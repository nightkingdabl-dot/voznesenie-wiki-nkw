# Вознесение Wiki — Cloudflare

Это версия специально под Cloudflare Workers + D1. **Все файлы лежат в корне**, без папок — удобно загружать с телефона в GitHub.

## Что добавлено
- Поиск по ключевым словам: название, описание, текст и теги.
- Теги у каждой статьи и быстрый поиск по тегу.
- Категории и подкатегории.
- Красивый адаптивный дизайн.
- Чтение без входа.
- Регистрация/вход по желанию.
- Админка: статьи, категории, пользователи.
- Админ может назначать других админов, блокировать и удалять пользователей.
- Cloudflare D1 для постоянного хранения.

## 1. Создай D1
Cloudflare → Workers & Pages → D1 → Create database.
Имя: `voznesenie-wiki-db`.
После создания открой SQL Console и выполни весь `schema.sql`.

## 2. Укажи ID базы
В `wrangler.toml` замени `REPLACE_WITH_YOUR_D1_DATABASE_ID` на реальный Database ID.

## 3. GitHub → Cloudflare
Загрузи **все файлы из ZIP прямо в корень репозитория**.
В Cloudflare подключи GitHub-репозиторий к Workers Builds.

Поля на твоём экране:
- Build command: `npm install`
- Deploy command: `npx wrangler deploy`
- Version command: оставить пустым
- Root directory: `/`

## 4. Первый вход
Логин: `NIGHT_KING`
Пароль: `vozn_04`

После первого запуска рекомендуется сменить пароль администратора. В этой сборке начальный пароль зашит как bootstrap-доступ; для серьёзного публичного запуска его стоит заменить в `worker.js` перед деплоем.

## Если Cloudflare ругается на D1
Проверь, что ID базы в `wrangler.toml` реальный и что SQL из `schema.sql` уже выполнен.
