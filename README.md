# Вознесение Wiki — Cloudflare Workers + D1

Готовая мобильная Wiki без папок и без assets-директории. Весь интерфейс и серверная логика находятся в `worker.js`, поэтому `node_modules` не загружается как Worker Assets.

## Cloudflare

Build command: `npm install`

Deploy command: `npx wrangler deploy`

Version command: пусто

Root directory: `/`

D1 уже прописан в `wrangler.toml`:

### Фотографии

Фотографии хранятся в D1 как BLOB, поэтому отдельный R2 bucket не нужен. Cloudflare D1 ограничивает BLOB/строку/строку таблицы 2 МБ, поэтому интерфейс принимает изображения до 1,9 МБ. Для мобильной загрузки лучше использовать JPG/WebP и при необходимости предварительно уменьшать фото.

### Важно

В проекте используется PBKDF2 с 100000 итераций, совместимый с Cloudflare Workers.
